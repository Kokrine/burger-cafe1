# ჩემი ბურგერების კაფე

სასწავლო მათემატიკური თამაში 1–4 კლასისთვის. მოსწავლე მართავს ვირტუალურ კაფეს:
ყიდულობს ინგრედიენტებს, აწყობს ბურგერებს, ემსახურება კლიენტებს, ითვლის ხურდას,
შემოსავალს, ხარჯს და მოგებას, ყიდულობს ინვენტარს და აფართოებს კაფეს.

Phaser 3 + TypeScript + Vite. მენიუები — უბრალო HTML/CSS. ყველა გრაფიკა — კოდით
გენერირებული SVG (`scripts/assets` → `public/assets`).

## გაშვება

```bash
npm install
npm run dev        # http://localhost:5173 (ასეტებიც გენერირდება)
npm test           # unit ტესტები (vitest)
npm run build      # საბოლოო ვერსია dist/-ში
```

## შესვლა (ოფლაინ რეჟიმი)

ახლა მონაცემები ინახება მოწყობილობის localStorage-ში. პირველ გაშვებაზე იქმნება
სატესტო დემო კლასი — მისი კოდი, მოსწავლეები, PIN და მასწავლებლის ანგარიში
ჩაწერილია ფაილში [`src/data/demo.ts`](src/data/demo.ts).

* **მოსწავლე:** კლასის კოდი → სახელი სიიდან → 4-ნიშნა PIN.
* **მასწავლებელი:** ელფოსტა + პაროლი → კლასის შექმნა (6-სიმბოლოიანი კოდი, დონე 1–4),
  მოსწავლეების დამატება (PIN ჩანს ერთხელ), PIN-ის აღდგენა, სიზუსტე ოპერაციებით.
* **სტუმარი:** თამაში შესვლის გარეშე (ძველი შენახვაც ამით გრძელდება).

ოფლაინ რეჟიმი ერთი მოწყობილობისთვისაა (PIN/პაროლი ინახება SHA-256 ჰეშით).
რეალური დაცვისთვის — Supabase.

## Supabase (მომდევნო ნაბიჯი)

1. შექმენი პროექტი supabase.com-ზე.
2. SQL Editor-ში გაუშვი [`supabase/schema.sql`](supabase/schema.sql) — ცხრილები,
   ფუნქციები და Row Level Security (მოსწავლე ხედავს მხოლოდ საკუთარ მონაცემებს,
   მასწავლებელი — მხოლოდ თავისი კლასისას).
3. Authentication → Providers: ჩართე **Email** და **Anonymous sign-ins**.
4. `.env`-ში: `VITE_SUPABASE_URL` და `VITE_SUPABASE_ANON_KEY`.
5. დაემატება `src/data/supabase.ts` — `Backend` ინტერფეისის რეალიზაცია
   ([`src/data/backend.ts`](src/data/backend.ts)); თამაშის დანარჩენი კოდი არ იცვლება.
